# API кулінарної книги

Практична робота №6  
Варіант №6 — Кулінарна книга

## Ресурс

`recipes`

Поля рецепта:

- `id` — ідентифікатор;
- `title` — назва страви;
- `ingredients` — інгредієнти;
- `cook_time_min` — час приготування у хвилинах.

---

## 1. Отримати всі рецепти

### Запит

GET

/api.php?resource=recipes

### Успішна відповідь

HTTP 200

```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "title": "Паста",
      "ingredients": "макарони, томати, сир",
      "cook_time_min": 25
    }
  ]
}
